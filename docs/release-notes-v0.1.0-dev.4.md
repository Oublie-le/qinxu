# 琴序 v0.1.0-dev.4 · 开发预览

本次汇总 `v0.1.0-dev.3` 以来的原生界面、教材练习、持音与复盘，以及全局节拍器更新。发布内容为源码开发预览；iPad / iPhone 需自行使用 Xcode 构建签名，本次不提供可直接安装的 IPA，也未发布到 App Store。

- **原生界面与图标**：米白、墨绿、朱砂配色，曲库搜索、小封面、收藏、谱架、本地封面与详情；iPhone 横屏、iPad 横竖屏。应用图标使用已确认的原创琴键图像，保留原图构图和配色。
- **全局节拍器**：曲库和练习页均可打开；拍号、速度音符、每分钟次数和每响一次的音符分别设置并保存。例如 3/4 拍、四分音符每分钟 90 次、每响八分音符，即每拍响两次。独立启动后可跨选曲和应用内导航继续；随练习启动时随练习暂停。进入后台停止，重启恢复设置但不自动播放。
- **曲谱与速度分开处理**：全局拍号决定节拍器重拍循环和预备拍，保留曲谱原拍号及小节结构。换曲、重练、续练均使用当前保存的全局速度，旧进度不会覆盖它。麦克风实际录音期间只闪拍、不播放节拍声；打开全局设置会暂停当前练习与录音。
- **长音与沉浸练习**：整首固定键盘音域，下一待弹音与应保持的长音分别提示；显示剩余拍数、秒数和递减进度，以采集起点计算。沉浸模式保留谱面、琴键及播放控制。长音提示表达谱面要求，不代表实际物理按键或踏板时长。
- **续练与报告**：保存安全小节、声部和模式；识谱报告显示真实正确/错音及音高准确率，完整节奏练习增加起音偏差、早晚、漏音、问题小节与建议。总分按 70% 音高准确率、30% 节奏分计算；识谱模式、未完成练习和续练片段不生成完整节奏总分，松键时长不计分。
- **拜厄教材**：增加 59 项中文重排练习，覆盖 39 首原曲，可从教材目录进入判音练习；另有完整 88 页外文公版原书供离线阅读。中文练习并非完整 106 首，也不是上海音乐出版社中文版；PDF 本身不判音。上海版小汤 1/2/3 的完整电子谱仍未取得、未内置。
- **乐谱与本机数据**：使用 Bravura 字体显示简化双谱表；收藏、封面、续练和节拍器设置保存在本机。写入失败不发布假成功，损坏或不支持的新版本存储保留恢复副本。
- **独立多音实验**：接入本机 Basic Pitch CoreML，保留 C3–C6 单音实验入口。多音使用约 2 秒音频窗口，仅用于识谱等待，不评价节奏或物理松键；实录开发检查仍有明显漏音，目标 iPad 电钢琴的准确率、延迟与持续性能尚未完成实琴验收。

首次克隆或下载源码后，先运行 `bash scripts/prepare-resources.sh`，获取并校验固定版本的模型、Bravura 字体和公版 PDF。个人签名可通过 `scripts/configure-ios-signing.py` 写入被 Git 忽略的本地配置，凭证不进入仓库。Mac 应用仅作共享代码开发预览。

验证：本机 **154 项自动测试、iOS Simulator 构建、iPhone 完整 12/12 UI 测试通过**；目标实体 iPad 的 12 条路径均有通过证据（首轮 10/12，修正后定向 2/2），签名、安装和正常数据模式启动通过。[远程检查](https://github.com/Oublie-le/qinxu/actions/runs/45649432371)的共享验证与 iPad 12/12 通过，iPhone 11/12；唯一搜索等待超时在本机未复现，正在单独复核。因此本次为开发分支的预览发布，`main` 暂保留此前验证基线。原始失败与复测均保留记录。

具体构建步骤见[README](https://github.com/Oublie-le/qinxu/blob/v0.1.0-dev.4/README.md)；实际执行过的构建、自动测试和 iPad UI 结果见[验证记录](https://github.com/Oublie-le/qinxu/blob/v0.1.0-dev.4/docs/STATUS.md)。这些记录不替代实琴 MIDI、多音准确率或节拍声学/路由验收；多音的实录结果与限制见[实验说明](https://github.com/Oublie-le/qinxu/blob/v0.1.0-dev.4/docs/POLYPHONIC_MICROPHONE.md)。
