# 真机验收清单

这些条目需要真实设备，不因自动测试通过而自动勾选。

## 环境登记

- [ ] iPad / iPhone 型号、iOS 版本、方向与缩放设置。
- [ ] 钢琴品牌/型号、USB 或转接器型号、是否供电。
- [ ] Xcode 版本、构建版本、签名账号已正确配置。

## MIDI

- [ ] 初次连接、热插拔、重连、选择其他来源时状态正确。
- [ ] C4 等已知琴键对应正确 MIDI 音高；Note On velocity=0 释放正确。
- [ ] 双手和弦、同音重击、跨 MIDI 通道、踏板不产生卡键或重复判定。
- [ ] 「晨光」完整练习正确前进，故意错一个音后能继续。
- [ ] 「并肩」同时按四音及分手练习均可进行。
- [ ] 节奏模式倒数结束后第一音可命中；故意漏音后游标继续。
- [ ] 最后一音按键时长、暂停中的释放、切后台后的释放不误报。
- [ ] 循环只重复所选小节，完成记录不重复写入同一遍。

## 曲谱与界面

- [ ] 示例 XML 导入后与内置音符、时值一致。
- [ ] 从实际打谱软件导出单钢琴 MusicXML 验证，unsupported 的谱子有清楚提示。
- [ ] 大谱表、升降音、弱起、休止、附点、连音的显示与数据核对。
- [ ] iPad 横竖屏与 iPhone 窄屏无遮挡，琴键可按、弹窗可关闭。
- [ ] 重启应用后曲库、最近曲目、完成记录保留。

## 麦克风（实验）

- [ ] 权限同意/拒绝/从系统设置撤销均能正确处理。
- [ ] 安静环境，C3–C6 单音，不踩踏板，记录力度和距离变化下的误判。
- [ ] 真实琴同音连续重击的局限有实测记录。
- [ ] 和弦曲目被明确限制，不作为双手识音演示。
- [ ] 切后台、音频路由变化、蓝牙耳机、来电后不会崩溃或继续偷偷录音。
- [ ] 实测反馈延迟、10 分钟持续运行的耗电与温度。

## 发布门槛

只有完成 iOS 构建、设备流程和目标练习曲的回归测试后，才可标记为「自用 MIDI 版可验收」。麦克风识音另设门槛；当前不具备 App Store 发布验收结论。
