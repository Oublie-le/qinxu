## 麦克风（实验）

用户已试用并报告“识别对了”，同时发现键盘布局随目标变化、长音高亮过快消失。这是实机体验反馈，不是有真值标注的准确率/多音/踏板验收。修复后的体验仍需再次确认。

- [ ] 权限同意/拒绝/从系统设置撤销均能正确处理。
- [ ] 安静环境，C3–C6 单音，不踩踏板，记录力度和距离变化下的误判。
- [ ] 真实琴同音连续重击的局限有实测记录。
- [ ] 原单音模式仍拒绝和弦；多音选择独立「双手 · 实验」入口，不得混写测试结果。
- [ ] 多音：双手同时 3/4/5 音，逐音真值记录 TP/FP/FN；左右手低音/高音分开统计。
- [ ] 多音：同音重击、和弦换位、分解和弦、不同力度，无踏板/半踏板/全踏板分别测。
- [ ] 多音：记录首次缓冲时间、起音到界面反馈中位/P95 延迟及单次推理耗时；Mac 推理耗时不作为 iPad 数据。
- [ ] 多音：不因预期谱音补全和弦，不显示节奏或物理松键时长评分。
- [ ] 麦克风实际录音期间节拍器仅闪拍且声音按钮禁用，报告注明实验来源；停止录音后可独立播放节拍。只选择麦克风但尚未录音时，不误判为正在录音。
- [ ] 确认绿色待弹、浅橙应保持与橙色声音含义清楚：声学 off 后谱面长音仍按时值保留，余音不触发下一次判音；缓冲结果不从送达时刻重新计满长音。
- [ ] 双手麦克风在循环尾音等待期间停止、暂停或切后台，录音停止且循环不自行重启。
- [ ] 切后台、音频路由变化、蓝牙耳机、来电后不会崩溃或继续偷偷录音。
- [ ] 实测反馈延迟、10 分钟持续运行的耗电与温度。
