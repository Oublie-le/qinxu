# 当前进度与验证记录

更新日期：2026-11-25。产品：琴序（QinXu）。当前版本：0.1.0 开发版。M0 工程、核心及自动化验收已完成；已补齐远程 iOS 编译与基础 UI 验收，M1 的实琴真机验收待环境和设备就绪。

## 已实现

- 原生 SwiftUI 界面与 iOS 工程；同一代码的 macOS 开发预览。
- MusicXML 有界解析，三首原创样谱及可编辑示例文件。
- MIDI 来源选择、按下/松开/踏板解码、断线暂停。
- 识谱等待、和弦、重复音、固定速度节奏、错音/漏音与按键时长提示。
- 分手练习、调速、一小节预备、按拍号节拍重音、小节循环。
- 屏幕琴键输入；导入曲库、完成记录与损坏文件恢复副本。
- 新练习界面优先显示谱面与音符反馈，键盘紧随其后。播放与分手控制固定在底部，调速、循环和输入设备移入设置。宽屏并排显示可搜索的曲库与谱面。
- 实验性 C3–C6 麦克风单音识别；权限处理与后台停止。

## 明确限制

- 简化练习谱不是出版级排版。非标准时值附数值标注；当前目标音还显示拍数与对应秒数。
- 导入不支持 MXL、PDF/照片、反复跳转、变速变拍、移调等；遇到这些情况明确拒绝。
- 从跨小节延音线中间开始循环会明确提示改从前一音起始小节练习，避免漏掉持续音。
- 麦克风只在逐个单音、识谱模式下实验，不用于双手和弦或节奏评分。
- 屏幕琴键是输入方式，当前不合成钢琴音色。
- 真机签名、iOS 麦克风权限和文件导入弹窗、真实 MIDI 延迟、音频路由、长期性能和实琴识音尚需完成，不能宣称已可上架。
