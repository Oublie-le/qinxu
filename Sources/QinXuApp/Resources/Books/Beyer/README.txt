转换内容与边界：
- 只提取学生的左右手；不要求用户弹教师伴奏。
- 音高、左右手与起点来自公开 notes.json，并逐音核对公开 SVG 的谱表位置。
- 时值来自 SVG 的全/二分/四分音符音头、附点和独立符尾（第61首含八分音符）；
  不把 JSON 中经过播放门控的
  0.9983 等时长当作原谱四分音符时值。所有所选音符的两种时长差均小于0.01拍。
- 反复按照公开演奏顺序展开，生成连续小节号；每首具体情况见 manifest.json。
- 第1、2首的主题与变奏按原书的完整段落拆分；没有截取部分小节冒充全曲。
- 保留来源 SVG 的高音/低音谱号，双高音谱表不改成高低谱表。
  当前45项练习为双高音，14项为高低音；谱号不决定左右手归属，音高不移调。
  verification.json 逐项记录起始谱号和小节边界换谱号；小节内换谱号尚未支持，遇到时明确拒绝。
- 仅中文重排练习所需的音高、时值和左右手；指法、力度与连奏线应参照原书。
- 默认速度取公开练习数据，供用户调节，不声称它是作曲家唯一指定的速度。

复现与核验：
scripts/import-beyer-ranote.py --fetch --check
脚本仅下载公开页面直接引用的文件；不绕过登录、付费或访问控制。
source-lock.json 固定每一份输入的 URL、字节数及 SHA-256；来源变化时校验失败。
verification.json 记录每一完整条目的小节数、音符数、拍数和反复展开状态。
进一步由应用的 MusicXMLParser 读取，并由应用测试核验实际可练习的数据。
